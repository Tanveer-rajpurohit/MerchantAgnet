MerchantOS – Personal AI Ops Agent for Indian Merchants (Open Track)
One-line Pitch
An always-on multi-agent AI co-pilot for Indian small & mid merchants that watches revenue, controls spending, creates payment links, tracks budget, forecasts cash, and closes daily money loops — all via simple Hindi/English chat, powered by Razorpay test-mode APIs.
The Real Problem
Most Indian merchants (kirana, D2C, services, local e-com) run on WhatsApp + Excel + memory. They lose money daily because:

No real-time view of revenue vs expenses
Manual/slow payment-link creation and collection
No clear “remaining budget” or “can I afford this?” answer
Future obligations (rent, salaries, suppliers, GST) ignored until crisis
Painful reconciliation

Razorpay already handles payments. Merchants lack the intelligent layer that acts on that data.

Core Product Vision
Merchant onboards once (connects Razorpay test account + uploads/sets fixed expenses, products, past statements).

After that they just chat (web chat or WhatsApp-style interface):

“Aaj ka revenue kitna hua?”
“Kal ka expected cash position batao”
“Yeh customer ko 4,500 ka payment link bhejo”
“Supplier se 12k ka maal order karna hai, budget mein hai kya?”
“Is mahine kitna margin bacha hai?”
“Salary + rent ke baad kitna free cash rahega?”

The multi-agent system does the rest.

Functional Requirements
1. Onboarding & Data Ingestion

Connect Razorpay test account (Key ID + Secret)
Set monthly fixed costs (rent, salaries, EMI, GST estimate)
Upload or enter past transactions / products / variable costs
Store merchant profile + preferences (language, currency INR, timezone)

2. Natural Language Interface

Hindi + English chat (Hinglish supported)
Intent detection + entity extraction (amount, customer name, order ID, date range)
Multi-turn conversation with memory
Confirmation step before any money-moving action (payment link creation)

3. Daily Revenue & Cash Pulse

Pull payments, settlements, success/failure rates from Razorpay
Answer “Aaj ka collection”, “pending”, “failed”, “net settlements”
Simple dashboard cards + natural language summary

4. Budget & Remaining Money Guardian

Track every outflow against plan
Real-time “remaining budget” calculation
Warn or soft-block overspend with clear reason

5. Smart Payment Link Factory

One command → create Razorpay Payment Link (or QR) with amount, description, customer details, expiry
Support partial payments + reminders
Return shareable link or send via simulated WhatsApp/email in demo

6. Expense & Purchase Advisor

“I need to buy X for ₹Y” → check current cash + known upcoming outflows → Yes / No / Partial with numbers and reasons

7. Forward Cash Forecaster (7–14 days)

Simple, transparent forecast: expected inflows (recent patterns) – known outflows – buffer
Flag risk days clearly

8. Multi-Agent Orchestration

Revenue Agent (payments, settlements)
Budget Agent (spend vs plan)
Action Agent (create links, record expenses)
Forecast Agent
Orchestrator (routes, maintains memory, audit log)
Every action logged with timestamp, input, output, success/failure

9. Audit & Recovery

Full audit trail visible to merchant
Graceful failure handling (API down → queue + notify; invalid amount → ask for correction)

10. Demo / Synthetic Data Mode

Pre-loaded realistic merchant data (50–200 transactions, fixed expenses, products)
Ability to reset or switch merchants for demo

WhatsApp Integration (Free & Fast)How it works for merchants:
Merchant messages your bot first (e.g. @MerchantAgent or a dedicated number).
They type naturally:
make payment link of 300
create 4500 link for Rahul order 482
aaj ka revenue kitna hua
Bot replies inside the same chat with the Razorpay test payment link + short confirmation.
Merchant simply forwards that message (or the link) to any customer on WhatsApp. No extra steps.
“Chat with other users / direct forward from AI” option

In the web app you can add a toggle:

“Send link directly to customer’s number” (merchant enters customer phone).

For pure free mode, the safest and cleanest is: AI generates the link → merchant forwards it. This avoids Meta’s paid outbound template costs and stays 100% free.
